# Site público do Sou (GitHub Pages)

Páginas exigidas pela Google Play: política de privacidade e exclusão de conta.

Para publicar, copie o conteúdo desta pasta para a raiz de um repositório **público**
(ex.: `sou-app`) e ative *Settings → Pages → Deploy from a branch → main / (root)*.
URLs resultantes:

- `https://<usuario>.github.io/sou-app/privacidade`
- `https://<usuario>.github.io/sou-app/exclusao-de-conta`
