# Política de Privacidade — Sou

Última atualização: 27/09/2026

## 1. Visão geral

O **Sou** é um aplicativo Android de gerenciamento de finanças pessoais. Esta política explica quais dados o aplicativo usa, para qual finalidade, onde eles ficam armazenados e como o usuário pode excluir a conta e os dados associados.

## 2. Dados tratados pelo app

### 2.1 Dados de autenticação

O acesso ao app é feito com a conta Google, por meio do Google Sign-In e do Firebase Authentication. Nesse processo são tratados:

- nome
- e-mail
- foto de perfil
- identificador da conta autenticada

Esses dados são usados somente para identificar o usuário no aplicativo e permitir o acesso. Eles são processados pelos serviços do Google/Firebase, de acordo com a [Política de Privacidade do Google](https://policies.google.com/privacy).

### 2.2 Dados financeiros informados pelo usuário

O usuário pode registrar contas financeiras, categorias de receita e despesa, receitas, despesas, transferências, contas a pagar e a receber, saldos e anexos (como comprovantes).

Esses dados ficam armazenados **somente no dispositivo do usuário**. Eles não são enviados a servidores do desenvolvedor nem a terceiros.

### 2.3 Backups

O recurso de backup salva uma cópia dos dados financeiros do perfil em uma pasta privada do app no próprio aparelho (são mantidos os três mais recentes). O usuário pode, por iniciativa própria, exportar um backup usando o compartilhamento do Android (por exemplo, e-mail ou Google Drive). Nesse caso, o arquivo passa a ser tratado pelo serviço escolhido pelo usuário.

### 2.4 Preferências locais

O app armazena localmente preferências como moeda, tema, uso de biometria para desbloqueio e lembretes de contas a vencer.

### 2.5 Permissões

- **Internet:** usada apenas para o login com Google/Firebase.
- **Notificações:** usadas para lembrar o usuário de contas a pagar e a receber. As notificações são geradas localmente.
- **Biometria:** usada, quando ativada pelo usuário, para desbloquear o app. O app não tem acesso aos dados biométricos, que são verificados pelo próprio Android.

## 3. Como os dados são usados

- autenticar o usuário e manter a sessão ativa;
- exibir, organizar e calcular os registros financeiros;
- gerar lembretes de vencimento;
- proteger o acesso com biometria, quando ativada.

O app não exibe anúncios e não vende nem compartilha dados com terceiros para fins de publicidade.

## 4. Compartilhamento

Os registros financeiros não são compartilhados. Para autenticação, o app utiliza o Google e o Firebase Authentication (Google LLC).

## 5. Armazenamento e segurança

- Dados financeiros e preferências ficam no armazenamento privado do app no dispositivo.
- O backup automático do Android está desativado, para que os dados financeiros não sejam copiados para a nuvem sem ação do usuário.
- A comunicação com os serviços de autenticação é criptografada (HTTPS).
- O acesso ao app pode ser protegido por biometria.

## 6. Exclusão de conta e dados

O usuário pode excluir a conta no próprio app, em **Configurações → Excluir conta e dados**. A exclusão remove a conta do app no Firebase Authentication e apaga do aparelho os dados financeiros, anexos, backups e preferências vinculados ao perfil. A conta Google do usuário não é excluída.

Também é possível solicitar a exclusão sem o app. Veja [Exclusão de conta](exclusao-de-conta).

## 7. Crianças

O app não é direcionado a menores de 18 anos.

Esta política pode ser atualizada para refletir mudanças no app, exigências legais ou regras da Google Play. A data no topo indica a versão vigente.
